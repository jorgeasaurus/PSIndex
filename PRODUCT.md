# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro (static output) with one Preact island for the search app, deployed on Vercel. Chosen by the user. Search runs in a Web Worker over columnar index shards generated at build time.

## Users

IT and Microsoft 365 administrators in the middle of a task: writing or debugging a PowerShell script. They need the exact cmdlet name, its syntax, the parameters, a working example, or the Graph permissions. Lookup speed matters more than browsing.

## Product Purpose

PSIndex is one searchable reference for the PowerShell surfaces an M365/endpoint admin uses: Microsoft Graph, Az, Entra, Exchange/Teams/SharePoint, and Configuration Manager (MECM). It replaces five separate sites (MgGraphIndex, AzIndex, EntraIndex, ExchIndex, MecmIndex). Error codes are out of scope (decided after launch); ErrorIndex remains a separate site. Success: an admin types a fragment and gets the right command and its syntax in seconds, whichever product it belongs to.

## Positioning

Cross-product, instant, offline-friendly lookup. Microsoft Learn is per-product and slow to navigate. PSIndex searches 41k cmdlets together, in the browser, with no backend.

## Operating Context

Used next to an editor or terminal, often on a second monitor, frequently opened from a bookmark or a pasted link. The data is regenerated by GitHub Actions from Microsoft's public documentation repos (`pipelines/`), committed to `data/`, and the site is rebuilt on push.

## Capabilities and Constraints

- Search by name, noun, or description fragment; filter by source, verb, module, category, API version (Graph/Entra), and examples present.
- Detail: syntax, parsed parameters, examples, permissions (Graph), link to Microsoft Learn.
- Deep links via URL query parameters.
- Static only. No accounts, no server.

## Brand Commitments

The user pinned the look: a modern UI with animated ASCII art effects in the background, in the spirit of ascii-magic.com's AI-coding-agent effects and joinariapp.com. (Neither reference could be fetched from the build environment, so the brief's words are the binding part.)

## Evidence on Hand

Real data only: `data/<source>/` from the pipelines. No usage stats, testimonials, or user counts exist; do not invent any.

## Product Principles

1. The search box is the product. Nothing competes with it in the first viewport.
2. Every entry answers "how do I call this?" without leaving the page.
3. One index, many sources: source is a filter, never a separate site.
4. The atmosphere never costs speed: effects pause, degrade, and respect reduced motion.

## Accessibility & Inclusion

WCAG 2.2 AA contrast; full keyboard operation (`/` to focus search, arrow keys through results, Enter to open, Esc to close); `prefers-reduced-motion` stops the ASCII animation.
